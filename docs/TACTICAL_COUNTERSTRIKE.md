# COUNTERSTRIKE — THE FALSE RELAY

A recovered SIGNAL COURIER transmission points the Pack to a false relay near the Dead Relay. HOUND patrols are known to be moving on it. The source of the transmission remains unresolved. This is an operational discovery in the Chain.

Story placement is after the server-recorded RECON 3/3 chapter and Broken Signal completion. The unfinished Dead Relay operation keeps its existing order and records. An active accepted operation blocks Counterstrike deployment. After victory, the next CTA points to the earliest actually available Dead Relay mission, or a current Field Op when that campaign is complete.

One mission uses the existing HOLD engine, exact-tile allied occupancy and adjacent hostile contesting. Hold for five consecutive round changes by round 12. Contest or loss of the holder resets progress. Two HOUND reinforcement waves enter in rounds 3 and 5. Clearing the patrol cannot finish the objective. Existing enemy archetypes, status resolution, profiles and damage formulas apply.

Two tested policies are SHADOW occupying the relay under Alpha/CNC screening and Alpha disrupting the patrol before holding the relay. Both win with base and maximum supported Alpha projections. Eight paired simulations completed in eight rounds with 36–40 allied commands. The 5–9 minute player pacing target requires human playtests.

RECON Intel is queried through the existing private chapter eligibility function. If available, acceptance consumes it once and freezes a one-round delay, moving entries to rounds 4 and 6. If already consumed in Dead Relay or any accepted run, baseline timing applies. A failed attempt keeps the consumption history. Resume reads the accepted contract, even after the feature flag changes. No old run is reconstructed.

The private implementation adds the counterstrike operation record to the existing Foundation operations map. It uses the existing authenticated routes, strict store, revisioned receipts and frozen V2/V3/build inputs. A new digest-pinned command worker decides completion. First clear and the last outcome are recorded without a new payout. The retained terminal run recovers an outcome if its command response is lost.

Public main contains the encounter, worker source, UI, host/store adapter and focused tests. Private Python source is delivered separately under COUNTERSTRIKE_BACKEND. Production capability, owner VPS hash comparison, deployment-environment staging, physical devices and the player pacing target remain release gates.
