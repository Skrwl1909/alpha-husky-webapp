# Meaningful Power P2 — bounded calibration and support policy
P1: owner reported 42/42 terminal victories. V3 first Forge gave 80→81 direct Alpha damage (tempo); P1 scaled gave 76→76. No HOWL, actual healing or registered interrupts; no evidence that a human cannot use them. Fresh control countered 8/8 warnings with zero damage; this is legal counterplay, not by itself a defect. P1 scaled respec gave 210 HP versus 120 fresh. V3 and raw/scale were not controlled for initiative or gear carry. P1 is experimental PASS, balance HOLD.

P2 changes ONLY the offline simulator. Retains P1 mode, reports separately. Same seven real backend-generated synthetic profiles; V3 vs P2 candidate, four scripted policies (tempo/control/pack/passive), 56 runs. Candidate uses canonical effective STR/DEF and bounded diminishing curves, keeps V3 initiative for each build, disables separate V3 gear carry to avoid counting the same source twice. Base VIT 0..100 is compressed (not discarded); gear/pet VIT and base excess retain a separate contribution. This is a provisional fairness compromise; current snapshot cannot distinguish historic baseline from earned VIT under 100. No level scaling. No production activation, worker parity, canonical RNG, crit, dodge or INT effects.

Pack attempts existing HOWL with a nearby ally, legal ATK_DOWN with relevant target, and existing support heals/DEF buffs for relevant recipients. It does not invent interruption capability. Records actual heal HP, status evidence, threat ledger and direct damage. Passive issues only legal skips, so no damage/attack credit for the player. Compare policies within matched profile/model; higher damage share alone is not evidence of useful support. Record terminal defeat as evidence, not error. If passive stalls, inspect report. A valid zero-damage control win can be a reward for skill, not something to eliminate arbitrarily.

Review gates: first Forge changes ATK and yields measurable combat evidence; offensive and guard profiles differ; fresh active route viable; veteran gains tempo without becoming the only useful unit; pack exercises at least one genuine beneficial support effect and costs an action; passive does not dominate active; inspect threat resolution and any stalls. Numeric assertions only validate conversion invariants and termination, not balance. No new deployment until independent worker parity and actual human/device QA.
